A two-line entry for the make.fun competition "Everyday Things, Two Lines, Longer Run".

Line 1 explains a toaster to a 10-year-old in one vivid analogy sentence — a tiny sun trapped in a metal box giving bread a quick suntan until it pops up golden-brown. Line 2 says what the analogy maps (the heat and the browning) and what it leaves out (a toaster has no sunshine of its own; it only borrows electricity to glow red-hot).

Run `python3 main.py` to write the entry to `/output/entry.txt`. Python standard library only.
